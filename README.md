# 🔍 Port Scanner - My First Cybersecurity Tool

### What is this?
A Python tool that scans ports of a target to find which ports are OPEN.

### Why I built it?
To learn how hackers find open ports and how defenders protect them. This is my first step in Cybersecurity.

### How to run?
1. Download scanner.py
2. Open terminal
3. Type: python scanner.py
4. Enter IP: 127.0.0.1

### Tools Used
- Python
- Socket Library
- VS Code

### What I learned?
- How TCP connection works
- How to use Python socket
- Ethical Hacking - Only scan your own systems
